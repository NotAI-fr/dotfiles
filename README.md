## 💻 Setup

* **WM:** i3
* **Terminal:** Kitty
* **Bar:** Polybar
* **Launcher:** Rofi
* **Wallpapers:** feh
* **Notifications:** Dunst

## 🎨 Features

* **Themes:** Monochrome, Everforest, Catppuccin Mocha, and Gruvbox.
* **Switchers:** Custom theme and wallpaper switching.
* **Organization:** Wallpapers are sorted and categorized locally in `~/Pictures/walls`.
